# AI Mitra Website – Change Report

## Requested changes implemented

1. Home page **About AI Mitra** button links to `about.html`.
2. Home page **Use AI Wisely** navigation/pathway/footer links were removed.
3. Home page Resources navigation and Free Resources pathway/footer links point to `resource.html`.
4. Home page **Invite AI Mitra to Your School** CTA opens a Google Form modal integration point.
5. AI in Real Life **Use AI Wisely** navigation and Explore CTA were removed; the useful cybersecurity/safety content remains.
6. The Home-page navigation design and same five destinations are used on all seven pages. The shared header is sticky and the mobile menu behaves consistently.
7. Each Resources **Explore** button now opens an inline PDF preview. A separate **Download PDF** control is displayed below the preview.
8. Added `index.html` as the default static-hosting entry point, while retaining `home.html`.

## Validation limitations

The Google Form is not live yet because the uploaded project did not include a published Google Forms URL. Add the URL to `js/site-config.js` as explained in `README.md`.

The package has been checked for local file references, link targets, PDF existence and JavaScript syntax. A full visual browser test is not represented as completed.
